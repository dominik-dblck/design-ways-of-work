# Names

A name says what a thing holds or does. A file's name says what it is for.

| Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Gate                                                                                                                 | Exceptions                                                                                                                                                                                     | Why                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| No ticket id, epic, criterion, contract row, recon finding or decision date in an identifier, a test title, an assertion message, a string or a comment.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | ESLint `wow/no-ticket-names` · ESLint `wow/comments-are-invariants`                                                  | the sheet's data, whose strings are the specification · a part named for the epic it holds, its values and the names its entry imports of them (`receipts/E04Run.ts`, `E04_RUN_RECEIPTS`, D13) | A ticket's number means nothing once it closes, its criteria renumber between stages, and the work trail already maps each criterion to its test. |
| A name says what it holds or does (`DOCUMENT_STATES`, `sheetView`, `moveOf`, `id`), never a placeholder (`x`, `q`, `data`, `E04_ROWS`); length is not the measure, what the name tells is. A test title says what is checked, an assertion message what failed.                                                                                                                                                                                                                                                                                                                                                                                                                      | `review` · ESLint `id-length` (at least 2 characters) · ESLint `no-restricted-syntax` (a placeholder, a count alone) | `_` for a parameter nobody reads · `bar`, a thing of the model · the names ESLint's suppressions hold, until renamed                                                                           | A name is documentation that cannot go stale; a placeholder sends the reader into the body.                                                       |
| A file's name takes its kind's case: TypeScript and JSON camelCase, a component's PascalCase, markdown, a table, a patch and an asset kebab-case; a name a tool or an agent opens by convention (`README`, `SKILL`, `CLAUDE`, `AGENTS`, `package.json`, `tsconfig.json`, `eslint-suppressions.json`) as it is, and a partial a skill includes `_{kebab}.md`. A folder is kebab-case; one holding a module's parts takes its module's name as it is (a component's folder, a module's beside it: `releaseRecord/` by `releaseRecord.ts`), and a tool's own its convention (`.claude`, `__tests__`). A repository names each exception once, in its scope's `nameCases`, with its why. | `lint:files`                                                                                                         | its scope's `nameCases`: a source by its key, a record by its id or key, an asset and a font by their source's name                                                                            | One rule for every folder: a name's case says its kind before the file is opened, and a new folder needs no rule of its own.                      |
| A type, an interface and a React component are PascalCase; a variable is camelCase or UPPER_SNAKE; a function and a parameter are camelCase; a boolean says it is one, `is`, `has`, `can`, `should`, `was`, `will` or `did` before its name (`isLive`, `hasDraft`).                                                                                                                                                                                                                                                                                                                                                                                                                  | ESLint `naming-convention`                                                                                           | a destructured name, which is its source's · the names ESLint's suppressions hold, until renamed                                                                                               | The case says what a name is before it is read; a boolean named as a noun (`live`, `table`) reads as the thing, not the answer.                   |
| An import names what it takes; an empty clause (`import type {} from`) is removed. A side-effect import names no clause.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | ESLint `import-x/no-empty-named-blocks` · ESLint `no-restricted-syntax` (an empty export)                            | none                                                                                                                                                                                           | An empty clause loads a module for nothing and reads like a dependency that is not there.                                                         |
| A skill's `description` says what it does and, in a "Use when …" clause, when to use it; at most 1024 characters.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `aSkillSaysWhatAndWhen`                                                                                              | —                                                                                                                                                                                              | A skill is picked by its description; one that says no when is picked by guess.                                                                   |
| A hook is its file's name, `use{What}.ts(x)`; a query hook `use{What}Query.tsx`, a mutation `use{What}Mutation.tsx`; a provider's context hooks are its own.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | ESLint `wow/hooks-named-for-their-file`                                                                              | —                                                                                                                                                                                              | The `use` prefix is what React's rules of hooks read.                                                                                             |
| A file in a drawer folder ends with its kind: in `utils/` `Utils` or `Adapters`, in `constants/` `Constants` or `Words`, in `types/` `Types` or `Answers`, in `providers/` `Provider`, in `services/` `Service`; in `utils/` a purpose stands before it, never the component's name alone (`boardPageTonesUtils.ts`, not `boardPageUtils.ts`).                                                                                                                                                                                                                                                                                                                                       | ESLint `wow/file-names-its-purpose` (a drawer's closing word)                                                        | —                                                                                                                                                                                              | The folder says the kind, the closing word says it again where the file is read alone: in an import, a search, a tab.                             |
| An entry is named for the module the others import (`featureView.ts`, namespace `FEATURE_VIEW`), camelCase as every module; a part for what it holds or does (`modelTerms.ts`, `scaleRules.ts`), or for the epic it holds (`E01.ts`).                                                                                                                                                                                                                                                                                                                                                                                                                                                | ESLint `wow/file-names-its-purpose`                                                                                  | —                                                                                                                                                                                              | The entry's name is its import path and its bundle's; the part's name says its job before it is opened.                                           |
| Types are `{area}Types.ts`, and a types file holds types alone; no `utils.ts`, `helpers.ts`, `common.ts`, `shared.ts` or `index.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | ESLint `wow/file-names-its-purpose`                                                                                  | —                                                                                                                                                                                              | The suffix says the kind; a drawer name says none.                                                                                                |
| A value a part exports is UPPER_SNAKE (`TICKET_CHECKLIST`), a function camelCase (`judgePair`); an entry's API names are camelCase (`Plans.ticketChecklist`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | ESLint `no-restricted-syntax` (the case of a name)                                                                   | none                                                                                                                                                                                           | At the call site the case says whether a name is read or called.                                                                                  |
| An import inside the homes is a relative path with its `.ts` extension (`./glossary/modelTerms.ts`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `tsc` (`allowImportingTsExtensions`) · ESLint `import-x/extensions`                                                  | —                                                                                                                                                                                              | The build side imports the files as modules with no loader (D14).                                                                                 |
| A doc of the process (`CLAUDE.md`, a skill, a rule file) names a file by its repository path (`docs/process/plans.ts · RULES`), never by the name of the `.js` bundle the build writes from it; a published path says so (`project/tickets.js`).                                                                                                                                                                                                                                                                                                                                                                                                                                     | `theProcessNamesNoBundle`                                                                                            | the build side's documents, which name its repository's paths (O13)                                                                                                                            | The agent opens the file it reads about; a bundle is not in the repository.                                                                       |
