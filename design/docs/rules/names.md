# Names

A name says what a thing holds or does. A
file's name says what it is for.

| Rule                                                                                                                                                                                                                                             | Gate                                                               | Exceptions                                                                                                                                                                                     | Why                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| No ticket id, criterion, contract row, recon finding or decision date in an identifier or a comment.                                                                                                                                             | `theCodeNamesNoTicket` · `commentsAreInvariants`                   | the sheet's data, whose strings are the specification · a part named for the epic it holds, its values and the names its entry imports of them (`receipts/E04Run.ts`, `E04_RUN_RECEIPTS`, D13) | A ticket's number means nothing once it closes; the sheet holds the trail.                              |
| A name says what it holds or does (`DOCUMENT_STATES`, `sheetView`, `moveOf`), never a placeholder (`x`, `data`, `ROWS`, `PART_ONE`); length is not the measure, what the name tells is.                                                          | `review` · ESLint `id-length` (at least 2 characters)              | `_` for a parameter nobody reads                                                                                                                                                               | A name is documentation that cannot go stale; a placeholder sends the reader into the body.             |
| An entry is named for the module the others import (`sheet-status.ts`, namespace `SHEET_STATUS`); a part is camelCase, named for what it holds or does (`modelTerms.ts`, `scaleRules.ts`), or for the epic it holds (`E18.ts`).                  | `aFileNamesItsPurpose`                                             | —                                                                                                                                                                                              | The entry's name is its import path and its bundle's; the part's name says its job before it is opened. |
| Types are `{area}Types.ts`, and a types file holds types alone; no `utils.ts`, `helpers.ts`, `common.ts`, `shared.ts` or `index.ts`.                                                                                                             | `aFileNamesItsPurpose`                                             | —                                                                                                                                                                                              | The suffix says the kind; a drawer name says none.                                                      |
| A value a part exports is UPPER_SNAKE (`TICKET_CHECKLIST`), a function camelCase (`judgePair`); an entry's API names are camelCase (`Plans.ticketChecklist`).                                                                                    | `aConstantIsUpperCase`                                             | none                                                                                                                                                                                           | At the call site the case says whether a name is read or called.                                        |
| An import names what it takes; an empty clause is removed.                                                                                                                                                                                       | `anImportTakesSomething`                                           | none                                                                                                                                                                                           | An empty clause loads a module for nothing and reads like a dependency that is not there.               |
| An import inside the homes is a relative path with its `.ts` extension (`./glossary/modelTerms.ts`).                                                                                                                                             | `tsc` (`allowImportingTsExtensions`) · `anImportNamesItsExtension` | —                                                                                                                                                                                              | The build side imports the files as modules with no loader (D14).                                       |
| A skill's `description` says what it does and when to use it (`Use when`), in at most 1024 characters; its `name` is its folder's (`design-{file}`).                                                                                             | `aSkillSaysWhatAndWhen`                                            | —                                                                                                                                                                                              | Claude Code picks a skill by its description alone.                                                     |
| A doc of the process (`CLAUDE.md`, a skill, a rule file) names a file by its repository path (`docs/process/plans.ts · RULES`), never by the name of the `.js` bundle the build writes from it; a published path says so (`project/tickets.js`). | `theDocsNameRealPaths`                                             | the build side's documents, which name its repository's paths (O13)                                                                                                                            | The agent opens the file it reads about; a bundle is not in the repository.                             |
