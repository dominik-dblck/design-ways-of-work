# Functions

A call says what each value is, and a body reads top to bottom. How long a function may be: `size.md`.

| Rule                                                                                                                                                                                                                                                        | Gate                                                | Exceptions                                                                                   | Why                                                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Past two parameters a function takes one object (`readSnapshots({ streamPrefix: '' })`).                                                                                                                                                                    | ESLint `no-restricted-syntax` (past two parameters) | a callback whose shape its caller decides (`map`, `reduce`, `replace`)                       | The call names each value, and two values of one type cannot swap without a word from the compiler.                 |
| No conditional nested in another (`a ? x : b ? y : z`, a ternary inside a template a ternary holds): a nested choice is an early return, a named part, or a lookup table when the cases are keys (`localesStateOf` in `packages/domain/gates/gateList.ts`). | ESLint `sonarjs/no-nested-conditional`              | —                                                                                            | A nested choice is read by holding its outer branch in mind; an early return or a table is read one case at a time. |
| A file that takes one object anywhere takes it everywhere: beside an export taking one object (`operation(at: { … })`), every export of two or more values takes one object too (every operation of the build side's store port is one).                    | ESLint `wow/one-call-style`                         | a one-argument function · a file wholly by position                                          | One style per file, so nobody checks which style an operation is in before calling it.                              |
| A module's top level declares and reads nothing outside itself: no DOM, window or global read at load (W44).                                                                                                                                                | ESLint `wow/reads-nothing-at-load`                  | an entry's footer, which the build writes · a file open on the sheet, named with its finding | Importing a file writes nothing and reads nothing, so the build side imports it as a module.                        |
