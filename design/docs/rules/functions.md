# Functions

A call says what each value is, and a
body reads top to bottom. How long a function may be: `size.md`.

| Rule                                                                                                                                                                                              | Gate                           | Exceptions                                                                                   | Why                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Past two parameters a function takes one object (`readSnapshots({ streamPrefix: '' })`).                                                                                                          | `argumentsPastTwoAreOneObject` | a callback whose shape its caller decides (`map`, `reduce`, `replace`)                       | The call names each value, and two values of one type cannot swap without a word from the compiler. |
| No ternary chain three deep (`a ? x : b ? y : c ? z : w`): early returns, one `if` per case, or a lookup table when the cases are keys (`localesStateOf` in `packages/domain/gates/gateList.ts`). | `noTernaryChains`              | —                                                                                            | A chain is read by counting colons; a table is read by its keys.                                    |
| A module's top level declares and reads nothing outside itself: no DOM, window or global read at load (D14).                                                                                      | `aModuleReadsNothingAtLoad`    | an entry's footer, which the build writes · a file open on the sheet, named with its finding | Importing a file writes nothing and reads nothing, so the build side imports it as a module.        |
