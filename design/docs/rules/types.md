# Types

A type holds the values the code can meet and no others.

| Rule                                                                                                                                                                                                                                                                    | Gate                                                                                                     | Exceptions                                                                                                                              | Why                                                                                                                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| No `any`.                                                                                                                                                                                                                                                               | ESLint `no-explicit-any`                                                                                 | —                                                                                                                                       | `any` switches the checker off for everything the value touches.                                                          |
| An exported function states its parameter and return types.                                                                                                                                                                                                             | ESLint `explicit-module-boundary-types`                                                                  | —                                                                                                                                       | The signature is the contract a caller reads; an inferred one changes when the body does.                                 |
| A type-only import is `import type`.                                                                                                                                                                                                                                    | ESLint `consistent-type-imports`                                                                         | —                                                                                                                                       | It is erased at build, so a client bundle never pulls a server module in through a type.                                  |
| A `switch` over a union handles every member.                                                                                                                                                                                                                           | ESLint `switch-exhaustiveness-check`                                                                     | —                                                                                                                                       | A member added to the union is a red line at every switch, not a silent fall-through.                                     |
| A field always present is not optional; shapes that differ are a discriminated union (`{ kind: 'error'; message } \| { kind: 'ok'; data }`), not one shape of optional fields; a union of literals stands where a boolean flag would.                                   | `review`                                                                                                 | a row of the sheet's data that leaves a field out, as written                                                                           | Each shape says what it carries, so no reader checks a field the shape cannot have.                                       |
| Data nobody mutates is `readonly` (`readonly T[]`, `.readonly()` on a schema).                                                                                                                                                                                          | ESLint `wow/data-is-readonly`                                                                            | a function's local · a tally a scan fills as it runs, named in `eslint.config.ts` (`mutable`)                                           | A mutation becomes a compile error instead of a shared-state bug.                                                         |
| The code compiles under one base both sides extend, `shared/tsconfig.base.json`: `strict` and the checks beside it; a side's own tsconfig adds its environment alone (target, modules, types, paths).                                                                   | `tsc` (pre-commit)                                                                                       | a stricter flag the base does not hold yet, in its own tsconfig once this side reads 0 on it, until both sides do and the base takes it | Strict is the floor every rule above stands on, and one base keeps both sides on one floor.                               |
| No non-null assertion (`!`): a value that may be absent is narrowed, given its fallback, or refused where it is read.                                                                                                                                                   | ESLint `no-non-null-assertion`                                                                           | —                                                                                                                                       | A `!` is a cast to present: the compiler takes the code's word, and an absent value fails far from where it went missing. |
| A brand is a zod brand declared in its home (`z.string().min(1).brand<'BlockId'>()`; the build side's `packages/domain/model/brands/`), never `string & { __brand }`.                                                                                                   | ESLint `no-restricted-syntax` (`__brand`) · ESLint `wow/production-syntax` (`.brand()` outside its home) | —                                                                                                                                       | The zod brand has a `parse`; the hand-written one can only be entered by a cast.                                          |
| A schema is strict at every depth (`z.strictObject`), an answer read off the wire as much as a body, a payload or a record: a key it does not name is refused.                                                                                                          | ESLint `wow/production-syntax` (a loose schema)                                                          | —                                                                                                                                       | Drift between the server and a screen fails a test, not a reader; one style, since an answer's rows were strict already.  |
| No deprecated API: what a declaration marks `@deprecated` is replaced by what it names instead.                                                                                                                                                                         | ESLint `no-deprecated`                                                                                   | ESLint's `builtinRules`, the one door to a core rule's module, deprecated with no successor                                             | A deprecated call breaks on its library's next major, and its successor is already written down.                          |
| A type takes the highest rung its set of values allows: a literal union (`'page' \| 'spec'`, `keyof typeof THE_TABLE`), then a narrowing tied to a sibling (`Record<GroupId, …>`), then a primitive, left for a value that is open (a sentence, an id the sheet mints). | `review`                                                                                                 | —                                                                                                                                       | A primitive where the set is known lets a wrong value compile.                                                            |
| No cast (`as`, `<T>`).                                                                                                                                                                                                                                                  | ESLint `consistent-type-assertions` (`assertionStyle: "never"`)                                          | `as const` · tests                                                                                                                      | A cast is the one place the compiler takes the code's word for it.                                                        |
| No `@ts-ignore`; `@ts-expect-error` stands only in a `*.test-d.ts`, where it is the proof.                                                                                                                                                                              | ESLint `ban-ts-comment`                                                                                  | —                                                                                                                                       | An error silenced in production code is an error nobody reads.                                                            |
| A rule or a checklist line is `{ id, says, why }` in an array, its id a kebab-case key that says what it does, cited as rule:{key}; a decision or a finding is cited by its number (`D25`, `O17`); a table the code reads by key is a `Record` (D26, D29).              | `checks` (each key once, each run of numbers without a gap) · `aCitedRowExists`                          | a decision’s own words, dated, which may cite a rule by its old number                                                                  | A citation by place points at the wrong row the day one is inserted above it, and a key says what it points at.           |
| A file reads another module by import, typed by that module, never off `globalThis`: no file declares a global.                                                                                                                                                         | `review`                                                                                                 | —                                                                                                                                       | An import is the module itself, never undefined, and its type cannot drift from it.                                       |
