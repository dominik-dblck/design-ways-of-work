# Responsibility

A file does one job, and its first
lines say which.

| Rule                                                                                                                                                                                                                   | Gate                                        | Exceptions                                                                                                                    | Why                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| A production file opens with a header of 1–3 bullets, each at most 80 characters.                                                                                                                                      | ESLint `wow/file-states-its-job`            | generated files · tests                                                                                                       | A fourth bullet is the file's second job showing; the split goes there.                           |
| Each bullet names, in backticks, the exports it describes; every exported value is in a bullet, and every name in backticks exists in the file.                                                                        | ESLint `wow/file-states-its-job`            | exported types, the vocabulary of the bullets                                                                                 | A rename or a new export turns the gate red instead of leaving the header to lie.                 |
| A file exports at most 15 values.                                                                                                                                                                                      | ESLint `wow/file-states-its-job`            | exported types · generated files · an entry passing on its parts' values as its namespace, its bullets naming each part (D14) | Past 15 a file is a catalogue, and three bullets cannot say what it is.                           |
| A value a production file exports is read by another file: imported by name, or with its module whole (`* as`, `export *`, `import()`, a glob); one only its own file reads is not exported.                           | `anExportIsRead`                            | a tool's export its `yarn` script runs · an entry's name the build side reads, listed in the scan at its sha (D14)            | An export no file imports is a door to nothing: its reader takes it for part of the file's offer. |
| A sheet file is an entry `{home}/{name}.ts` and its parts in `{home}/{name}/` (`tools/layout.ts`); a part serves its entry, and another entry reads it through that entry (`./test-cases.ts`), never through its part. | ESLint `wow/parts-serve-their-entry`        | —                                                                                                                             | The entry is the file's face (D13, D14); its parts can split and move behind it.                  |
| A tool sits in `tools/` behind a `yarn` script; a page's code is the sheet's, never a tool's.                                                                                                                          | `aToolIsAScript` · `review` (a page's code) | a tool a git or Claude Code hook runs                                                                                         | A tool is run by hand and never published; a page reads only what the artifact holds.             |
