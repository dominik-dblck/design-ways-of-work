# Components

For the React pages, once a page
moves (D7). The tiers are counted by tests that run on `app/components/` already; the rows still held by
`review` get their test with the first component.

| Rule                                                                                                                                                                                                               | Gate                                                                              | Exceptions | Why                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------- | ---------- | -------------------------------------------------------------------- |
| A tier is what a component imports from `app/components/`: an atom nothing, a molecule atoms and at most one other molecule, an organism two or more molecules or a screen's own flow, a template a page's layout. | `anAtomComposesNothing` · `aMoleculeComposesOneMolecule` · `review` (an organism) | —          | Counted, not judged, so two people sort a component the same way.    |
| A component file holds one component and its props type; a second component goes to `components/`, a type to `types/`, a helper to `utils/`, a constant to `constants/`, a hook to `hooks/`.                       | `review`                                                                          | —          | A file opened for a component shows that component and nothing else. |
| Hover text is a tooltip (the build side's `Hint`); no element carries a native `title`.                                                                                                                            | ESLint `wow/markup-syntax` (a hover text)                                         | —          | One look and one delay for every hover.                              |
| Every component is a row of `app/styles/components.spec.ts` (built into `fixtures/data/components.spec.json`).                                                                                                     | `review`                                                                          | —          | A shape the wireframes do not draw is a question, not a component.   |
| Every glyph is Lucide's, through `lucide-react` by name, never a copied SVG (D10).                                                                                                                                 | `review`                                                                          | —          | One set, one stroke, sizes from the tokens.                          |
| A page reads the sheet's entries as modules and holds no rule of the sheet; it draws the answer.                                                                                                                   | `review`                                                                          | —          | A rule copied onto a page is decided twice, and the copies drift.    |
