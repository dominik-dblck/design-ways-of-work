# Size

Limits count code: blank lines and comments
do not count.

| Rule                                                                                                                                                                                                  | Gate                                | Exceptions              | Why                                                                                                        |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------- |
| A file holds at most 200 lines of code.                                                                                                                                                               | ESLint `max-lines`                  | tests · generated files | A file past 200 lines holds a second job; the split is where that job gets its name.                       |
| A function holds at most 40 lines of code, a React component included.                                                                                                                                | ESLint `max-lines-per-function`     | tests                   | Past 40 lines a function is read by scrolling; its steps want names of their own.                          |
| A function's complexity is at most 10.                                                                                                                                                                | ESLint `complexity`                 | tests                   | Past ten paths a function is run in the head to be read; early returns or a lookup table read at a glance. |
| A block nests at most 3 deep.                                                                                                                                                                         | ESLint `max-depth`                  | tests                   | A fourth level is a function that has not been extracted yet.                                              |
| A file read whole when it loads (a skill, an entry it hands off to, a command) holds at most 2000 words, and one read on every turn (`CLAUDE.md`) at most 1000: the scope's `instructions` name them. | `everySkillIsShort`                 | —                       | A file read whole costs its words in context each time it loads; the work gets what is left.               |
| A file read on demand that runs past 100 lines opens with `## Contents`.                                                                                                                              | `everySkillIsShort`                 | —                       | A long file is often read in part; its contents show the whole scope to a partial read.                    |
| A rule file in `docs/rules/` holds at most 200 lines.                                                                                                                                                 | `everyRuleHasAGate`                 | —                       | A rule file is loaded by every review of its layer; past 200 lines it holds two concerns.                  |
| A split file is named by the job it holds, never by a number (`rowsTwo`, `part3`).                                                                                                                    | ESLint `wow/file-names-its-purpose` | —                       | A number says where the file was cut, not what it holds; the reader opens every part to find one.          |
