# One home

A fact is written in one place, and
everything else reads it from there (rule:one-source-of-truth).

| Rule                                                                                                                                                                                 | Gate                                                                                                                    | Exceptions                                                                                                      | Why                                                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| An exported name — a value, a type, a component — is declared in one file.                                                                                                           | ESLint `wow/one-home-per-name`                                                                                          | an entry's API names · a family's one name, which its loader reads from every file (`rules`, `skill`, `shared`) | Two declarations of one name are two things a reader takes for one, or one thing written twice.                                                            |
| A block of code is written once: fifty tokens alike, in two files or twice in one, become one function, type or constant that both read.                                             | `aBlockIsWrittenOnce`                                                                                                   | imports · tests · generated files · a pair open on the sheet, named with its finding                            | Two copies of a rule change apart and the fix reaches one; fifty tokens is jscpd's default, and a look-alike under it is judged by whether it is one rule. |
| No runtime import cycle.                                                                                                                                                             | ESLint `import-x/no-cycle`                                                                                              | type-only imports                                                                                               | A cycle lets load order decide behaviour, and a module mock does not survive it.                                                                           |
| A generated file is emitted from its source and never edited by hand.                                                                                                                | `aGeneratedFileIsItsModule` (the emitted modules, the rule files, the skills, `tokens.ts`) · `review` (`dist/`, a pack) | —                                                                                                               | A hand edit is lost on the next emit, or kept while its source says otherwise.                                                                             |
| A path a skill or a doc names in backticks exists; what the code lacks is removed from the doc, not kept as advice.                                                                  | `theDocsNameRealPaths`                                                                                                  | a placeholder (`{name}`, `*`)                                                                                   | A doc that names a missing path sends its reader looking for nothing.                                                                                      |
| An entry re-exports its own parts only, never another entry's or another entry's part.                                                                                               | `aPartServesItsEntry`                                                                                                   | —                                                                                                               | A second door to one name is a second home for it.                                                                                                         |
| A sentence a person sees is written once, in `sheet/words/messages.ts` or a type's `messages-{type}.js`; a fact the sheet holds is read from its home, never typed again.            | `checks`                                                                                                                | the words of a test's expected value, named in `source-check`                                                   | Two copies of a sentence are two places for it to differ.                                                                                                  |
| A sentence of the process is written once: in `CLAUDE.md`, a skill or a rule file, never in two; a rule's text lives in `docs/process/plans.ts · RULES` alone, and a skill names it. | `aSentenceIsWrittenOnce`                                                                                                | `legacy/`, the documents the skills were cut from                                                               | Two copies of a process line drift, and the session follows whichever it read last.                                                                        |
