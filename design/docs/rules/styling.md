# Styling

The look comes from the design system's
tokens; a page names a role, never a value.

| Rule                                                                                                                                                                             | Gate                    | Exceptions                                                                                                     | Why                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| In React code a colour is a palette role read through the theme: never a token variable, a typed value, a palette path on a `color` prop, nor `theme.palette` (the light value). | `aColourIsAPaletteRole` | —                                                                                                              | The theme holds the tokens, so a colour follows the mode and changes in one place.        |
| In React code a spacing or a radius is in theme units (`p: 1.75`), never a px string.                                                                                            | `aSpaceIsInThemeUnits`  | —                                                                                                              | A step of the scale moves in one place.                                                   |
| No HTML or CSS is written by hand: a page is TSX drawn with MUI and styled in JS (`sx`, the theme), never an HTML element, an inline style, CSS as a string or a stylesheet.     | `nothingIsRawHtmlOrCss` | `legacy/` until each page moves; `tokens.css` and the design system's files, which `tokens.ts` is written from | One way to style, so a look is read from the tokens and checked by the tests (PM, 4 Nov). |
