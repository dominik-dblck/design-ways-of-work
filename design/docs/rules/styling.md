# Styling

The look comes from the design system's tokens; code names a role, never a value.

| Rule                                                                                                                                                                                                                                                                                               | Gate                                                                                    | Exceptions                      | Why                                                                                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------ |
| A component writes no height; a corner, a layer, a weight and a fade are read by name off the design system's scales (`radiusOf('uiRCard')` on `borderRadius`, in the theme's units; a length on one corner, in px), never written as a number (a corner `0` or `'50%'`, a fade `0` or `1` aside). | ESLint `no-restricted-syntax` (a height, a corner, a layer)                             | —                               | Size follows content, layers stack in one known order, and a step of a scale moves in one place. |
| An sx object is written `as const`, checked where it is read; a function of the theme is typed `SxProps<Theme>`.                                                                                                                                                                                   | ESLint `no-restricted-syntax` (a loose sx)                                              | —                               | One form, checked where it is read · a type on the object widens what it holds.                  |
| In React code a colour is a palette role read through the theme: never a token variable, a typed value, a palette path on a `color` prop, nor `theme.palette` (the light value).                                                                                                                   | ESLint `no-restricted-syntax` (a colour)                                                | —                               | The theme holds the tokens, so a colour follows the mode and changes in one place.               |
| In React code a spacing or a radius is in theme units (`p: 1.75`, `radiusOf('uiRContainer')`), never a px string.                                                                                                                                                                                  | ESLint `no-restricted-syntax` (a space)                                                 | —                               | A step of the scale moves in one place.                                                          |
| No HTML or CSS is written by hand: a page is TSX drawn with MUI and styled in JS (`sx`, the theme), never an HTML element, an inline style, CSS as a string or a stylesheet.                                                                                                                       | ESLint `no-restricted-syntax` (raw markup) · `lint:files` (a stylesheet or a page file) | `legacy/` until each page moves | One way to style, so a look is read from the tokens and checked by the tests (PM, 4 Nov).        |
