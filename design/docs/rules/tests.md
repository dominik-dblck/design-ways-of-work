# Tests

A test sits where its project reads it and
proves something that can fail.

| Rule                                                                                                                                                                                                                                                                  | Gate                                             | Exceptions | Why                                                                                                                         |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ---------- | --------------------------------------------------------------------------------------------------------------------------- |
| A test imports the real function and asserts exact values; it never copies the logic, never mocks the module under test, and is seen red once with its condition broken.                                                                                              | ESLint `wow/no-mock-of-its-subject` · `review`   | —          | A test that cannot fail proves nothing.                                                                                     |
| A scan proves itself on a synthetic `{ path, text }`, never on a file planted in the tree.                                                                                                                                                                            | `review`                                         | —          | Suites walk the tree in parallel, and a planted file is read by every one of them.                                          |
| A scan that lands on code already breaking it starts from its list, `tests/architecture/baselines/{scan}.json`, written once with `BASELINES=write`; the list only shrinks: a new offender is red, and so is a fixed one still listed, until the next write drops it. | `baseline`                                       | —          | A gate that waits for the code to be clean never lands; one that lets the list grow holds nothing.                          |
| A skipped test names what it waits on.                                                                                                                                                                                                                                | `aTestLivesUnderTests`                           | —          | A skip without its reason becomes permanent.                                                                                |
| Production reads no test switch.                                                                                                                                                                                                                                      | ESLint `wow/production-syntax` (a test switch)   | —          | A branch only a test takes ships untested in the other direction.                                                           |
| A drawn element is asserted present one way, `expect(getBy…(…)).toBeTruthy()`.                                                                                                                                                                                        | ESLint `no-restricted-syntax` (a presence)       | —          | A `getBy` already throws when nothing is drawn; `toBeDefined` and `not.toBeNull` beside it are one fact in three spellings. |
| Time is moved with fake timers (`vi.useFakeTimers`, `page.clock`), never waited out.                                                                                                                                                                                  | ESLint `no-restricted-syntax` (a wait)           | —          | A wait is slow and still flaky; a moved clock is neither.                                                                   |
| A test lives under `tests/`: a scan of the code in `tests/architecture/`, a test of a sheet file in `tests/sheet/`; the way of working's shared tests under `shared/tests/`.                                                                                          | `aTestLivesUnderTests` · `review` (which folder) | —          | The place of a file is its tier, so a test cannot quietly run somewhere else.                                               |
| A file that moves to TypeScript is held to the old file's behaviour, its outputs compared as JSON over broad inputs, before the old file goes.                                                                                                                        | `review`                                         | —          | The move changes the language, never the answer.                                                                            |
