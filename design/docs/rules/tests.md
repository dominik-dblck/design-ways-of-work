# Tests

A test sits where its project reads it and
proves something that can fail.

| Rule                                                                                                                                                                     | Gate                                             | Exceptions | Why                                                                                                |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ | ---------- | -------------------------------------------------------------------------------------------------- |
| A test lives under `tests/`: a scan of the code in `tests/architecture/`, a test of a sheet file in `tests/sheet/`.                                                      | `aTestLivesUnderTests` · `review` (which folder) | —          | The place of a file is its tier, so a test cannot quietly run somewhere else.                      |
| A test imports the real function and asserts exact values; it never copies the logic, never mocks the module under test, and is seen red once with its condition broken. | `review`                                         | —          | A test that cannot fail proves nothing.                                                            |
| A scan proves itself on a synthetic `{ path, text }`, never on a file planted in the tree.                                                                               | `review`                                         | —          | A planted file is read by every other scan.                                                        |
| A scan that lands on code already breaking it starts from a list in `tests/architecture/baselines/`, written once with `BASELINES=write`; the list only shrinks.         | `baseline`                                       | —          | A gate that waits for the code to be clean never lands; one that lets the list grow holds nothing. |
| A file that moves to TypeScript is held to the old file's behaviour, its outputs compared as JSON over broad inputs, before the old file goes.                           | `review`                                         | —          | The move changes the language, never the answer.                                                   |
| A skipped test names what it waits on.                                                                                                                                   | `aTestLivesUnderTests`                           | —          | A skip without its reason becomes permanent.                                                       |
| Production reads no test switch.                                                                                                                                         | `aTestLivesUnderTests`                           | —          | A branch only a test takes ships untested in the other direction.                                  |
