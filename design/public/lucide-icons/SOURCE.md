# lucide-icons

Glyphs from Lucide (lucide.dev), copied as they are: lucide-icons/lucide @ 1fae58d0a9c661a338036838caf3399b5507bab6 (main, 6 Oct 2026). LICENSE is theirs (ISC, some glyphs MIT from Feather) and travels with the files.

Every icon in the wireframes comes from here (IC3 · PM, 6 Oct): an <img src="lucide-icons/name.svg"> tinted by a filter token, or a span masked by the file and filled with the colour it stands in. The repository draws the same glyphs from lucide-react behind its icon wrappers. Brand logos (Slack, Apple, Android, Google, Facebook, Instagram, LinkedIn) are not icons and stay in assets/icons.

Add a glyph by copying its file from the same ref, never by drawing its path.
