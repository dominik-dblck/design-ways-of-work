# Data

How a screen reaches the server and keeps what it read: services, an entity's calls, query hooks.
How an answer comes back: `errors.md`.

| Rule                                                                                                                                                                                                                                                                                | Gate                                                               | Exceptions                                                                                                                                                                                                        | Why                                                                                                          |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| A service is one function per file, named like the file (`names.md`): in `app/services/` on the server, in `app/clients/{entity}/services/` for an entity's calls from the browser, or in an organism's `services/`.                                                                | `aServiceIsOneFunction`                                            | `handleRouteService.ts`, the edge kernel, and its parts in `app/services/handleRoute/`: the answers, the specs, the doors · `createPostgresStore`, which implements a port and lives in `packages/store-postgres` | One search finds the file and the function, and every caller imports the same one.                           |
| A service is `async` unless it waits on nothing; a sync one says why in its header (`openStoreService`, `buildRevisionService`).                                                                                                                                                    | `aServiceIsOneFunction`                                            | —                                                                                                                                                                                                                 | A promise that never yields makes every caller await nothing.                                                |
| An entity's calls live in `app/clients/{entity}/` (`groups`, `documents`, `assets`, `directory`), named by the entity (`deleteGroupService`, `useCommandDocumentMutation`) and imported by every screen that needs them; an organism keeps only its components, adapters and words. | `theServerIsReadThroughItsClient`                                  | —                                                                                                                                                                                                                 | A screen is one use of the domain; the call belongs to the entity.                                           |
| A query or mutation hook lives in `app/clients/{entity}/queries/`; no component holds a `queries/` of its own.                                                                                                                                                                      | `aComponentFolderIsStructured` · `theServerIsReadThroughItsClient` | —                                                                                                                                                                                                                 | A second hook over one entity is a second cache key that can disagree with the first.                        |
| Every folder and document read keys under one root, `contentQueryKeys`, and a write marks stale exactly the reads it moves.                                                                                                                                                         | `aRefusedWriteReadsAgain` · `theAssetWritesReadNarrowly`           | —                                                                                                                                                                                                                 | A write on one screen refreshes the counts, the lists and the open document on every other.                  |
| Every query client comes from `createQueryClient()` in `app/utils/queryClientUtils.ts`, which holds the retry and the freshness; a hook states only what differs, never the retry.                                                                                                  | `oneQueryClient`                                                   | —                                                                                                                                                                                                                 | One place decides how hard the app retries.                                                                  |
| A command's `commandId` is minted once per press (`mintCommandId`) and kept by that press's retries; the autosave keeps it for a save it resends.                                                                                                                                   | `theAutosave` · `everyDocumentCommandReplays`                      | —                                                                                                                                                                                                                 | The server answers a repeat with `replayed: true` instead of doing the work twice.                           |
| A create whose id is taken tries the next one with the same draft; an upload goes out as one multipart form.                                                                                                                                                                        | `aWriteGoesOutWhole`                                               | —                                                                                                                                                                                                                 | A write either lands whole or is refused whole.                                                              |
| `app/hooks/` holds hooks over the browser and the screen (`useFileDrop`, `useScrollFade`); a hook that reads the server is a query hook in `app/clients/`.                                                                                                                          | `theServerIsReadThroughItsClient`                                  | —                                                                                                                                                                                                                 | A hook named for the screen does not grow a second cache.                                                    |
| `app/utils/requestUtils.ts` (`errors.md`) takes `{ url, method, body }` and answers `{ ok: true, data } \| { ok: false, error }`; on `unauthenticated` it sends the page to `/signin?callbackUrl=` with the path it stood on, and on `/signin` itself goes nowhere.                 | `requestService.test`                                              | —                                                                                                                                                                                                                 | Every call passes through it, so a lapsed session is caught once, for every screen.                          |
| A feature service turns the transport's answer into the feature's words: a write lifts the refusal's sentence, a read a query uses throws, so the query's error state is what the screen branches on.                                                                               | `review`                                                           | —                                                                                                                                                                                                                 | The person reads why; the screen branches on one state.                                                      |
| A pure function that reads no environment lives in `utils/`, not `app/services/` (`requestService`, `cookieJarUtils`).                                                                                                                                                              | `noClientReadsTheEdge` · `review`                                  | —                                                                                                                                                                                                                 | A client may import it, and a module mock survives where the edge and the session service import each other. |
