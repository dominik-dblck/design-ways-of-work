# App Router

Pages and endpoints under `app/`: a page composes, an endpoint maps a verb to a handler, and the
handler asks the domain. Server and client components and the rest of App Router:
`.claude/patterns/nextjs-app-router.md`, until the pipeline's sync brings it here.

| Rule                                                                                                                                                                                                                             | Gate                                                                                                | Exceptions                                                         | Why                                                                                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| An endpoint folder under `app/api/` holds `route.ts`, which maps each HTTP verb to a handler and does nothing else (`export const GET = getGroupsRoute;`), and one `{action}Route.ts` per verb.                                  | `routeFilesOnlyMap`                                                                                 | a segment's config export (`dynamic` in `app/api/health/route.ts`) | `route.ts` is read to see which verbs an endpoint has; the logic sits where a test can reach it. |
| A handler answers through `handle()` with a query or a command: it opens no port, writes nothing, takes no lock, and counts, filters or sorts nothing the domain hands it.                                                       | `everyHandlerCallsHandle` · `noRouteOpensAPort` · `theRouteWritesNothing` · `theRouteCountsNothing` | the Auth.js route and the health check                             | The domain decides, so every caller gets the same answer.                                        |
| A page reads its address (`[id]`) through `routeAddressOf`, the one place it becomes a brand.                                                                                                                                    | `brandsCrossOnce`                                                                                   | —                                                                  | The parse is the check, so it happens once.                                                      |
| The root layout's body is `AppProvider` around the page; the layout resolves the session through the same `resolveSessionService` the routes call.                                                                               | `theLayoutHoldsTheProviders`                                                                        | —                                                                  | The page and the API see the same person.                                                        |
| A signed-out visitor sees `SignedOutGate`'s card in place of the page; `app/signin/page.tsx` renders `SignedOutScreen`, and Auth.js's `pages.signIn` and `pages.error` send a caller there. Nothing on the client guards a page. | `everyPathIsWalked` (signed out)                                                                    | —                                                                  | A page that hides itself protects pixels; the API protects the data.                             |
| Pages live flat under `app/` (`app/[channel]/[kind]/page.tsx`); a route group bounds a layout, never auth.                                                                                                                       | `theMapIsTheTree` · `review`                                                                        | —                                                                  | Who may see what is the edge's answer (`security.md`), not a folder's.                           |
| Independent reads on the server run together, in one `Promise.all`.                                                                                                                                                              | `review`                                                                                            | —                                                                  | Waits in a row add up; waits side by side take the longest one.                                  |
