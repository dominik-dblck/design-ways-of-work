# Functions

A call says what each value is, and a body reads top to bottom. How long a function may be: `size.md`.

| Rule                                                                                                                                                                                                                                                        | Gate                           | Exceptions                                                                                                                                     | Why                                                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Past two parameters a function takes one object (`readSnapshots({ streamPrefix: '' })`).                                                                                                                                                                    | `argumentsPastTwoAreOneObject` | a callback whose shape its caller decides (`map`, `reduce`, a React event handler)                                                             | The call names each value, and two values of one type cannot swap without a word from the compiler.                 |
| No conditional nested in another (`a ? x : b ? y : z`, a ternary inside a template a ternary holds): a nested choice is an early return, a named part, or a lookup table when the cases are keys (`localesStateOf` in `packages/domain/gates/gateList.ts`). | `noTernaryChains`              | until its port, where SonarJS's rule replaces it (its 26, 14 in production)                                                                    | A nested choice is read by holding its outer branch in mind; an early return or a table is read one case at a time. |
| A file that takes one object anywhere takes it everywhere: beside an export taking one object (`operation(at: { … })`), every export of two or more values takes one object too (every operation of the build side's store port is one).                    | `aFileTakesOneStyle`           | a one-argument function (`literally(specifier)`) · a file wholly by position (`filled(line, data)`) · the files on its list, which only shrink | One style per file, so nobody checks which style an operation is in before calling it.                              |
