# Names

A name says what a thing holds or does. A file's name says what it is for.

| Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Gate                                                                                         | Exceptions                                                                                                                                                                                                                                                        | Why                                                                                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No ticket id, epic, criterion, contract row, recon finding or decision date in an identifier, a test title, an assertion message, a string or a comment.                                                                                                                                                                                                                                                                                                                                                      | `theCodeNamesNoTicket`                                                                       | fixtures copied byte-exact (the release under `packages/domain/sheet/__fixtures__/`, `*.json`, `*.css`) · the ticket tooling (`scripts/readTicket.ts`, `scripts/ticketSnapshot.ts`, `tests/scripts/`) · a key into such data, listed by the scan by file and line | A ticket's number means nothing once it closes, its criteria renumber between stages, and the work trail already maps each criterion to its test.                                                        |
| A name says what it holds or does (`DOCUMENT_STATES`, `sheetView`, `moveOf`, `id`), never a placeholder (`x`, `q`, `data`, `E04_ROWS`); length is not the measure, what the name tells is. A test title says what is checked, an assertion message what failed.                                                                                                                                                                                                                                               | `review` · ESLint `id-length` (at least 2 characters), the one placeholder a machine can see | `_` for a parameter nobody reads · a one-letter name that is its field's own notation (`r`, `g`, `b` for colour channels), let through in place by a directive with its reason                                                                                    | A name is documentation that cannot go stale; a placeholder sends the reader into the body.                                                                                                              |
| A file's name takes its kind's case: TypeScript camelCase, a component's PascalCase, markdown kebab-case; a name a tool or an agent opens by convention (`README`, `SKILL`, `CLAUDE`, `AGENTS`) as it is, and a partial a skill includes `_{kebab}.md`. A folder is kebab-case; one holding a module's parts takes its module's name (a component's, an entry's), and a tool's own its convention (`.claude`, `__tests__`). A repository names each exception once, in its scope's `nameCases`, with its why. | `review`                                                                                     | until its port, where its scope names its own                                                                                                                                                                                                                     | One rule for every folder: a name's case says its kind before the file is opened, and a new folder needs no rule of its own.                                                                             |
| A type, an interface and a React component are PascalCase; a variable is camelCase or UPPER_SNAKE; a function and a parameter are camelCase; a boolean says it is one, `is`, `has`, `can`, `should`, `was`, `will` or `did` before its name (`isLive`, `hasDraft`).                                                                                                                                                                                                                                           | ESLint `naming-convention`                                                                   | a destructured name, which is its source's                                                                                                                                                                                                                        | The case says what a name is before it is read; a boolean named as a noun (`live`, `table`) reads as the thing, not the answer.                                                                          |
| An import names what it takes; an empty clause (`import type {} from`) is removed. A side-effect import names no clause.                                                                                                                                                                                                                                                                                                                                                                                      | `anImportTakesSomething`                                                                     | none                                                                                                                                                                                                                                                              | An empty clause loads a module for nothing and reads like a dependency that is not there.                                                                                                                |
| A skill's `description` says what it does and, in a "Use when …" clause, when to use it; at most 1024 characters.                                                                                                                                                                                                                                                                                                                                                                                             | `aSkillSaysWhatAndWhen`                                                                      | the skills on its list, which only shrink · the ticket skills, which the pipeline writes                                                                                                                                                                          | A skill is picked by its description; one that says no when is picked by guess.                                                                                                                          |
| A hook is its file's name, `use{What}.ts(x)`; a query hook `use{What}Query.tsx`, a mutation `use{What}Mutation.tsx`; a provider's context hooks are its own.                                                                                                                                                                                                                                                                                                                                                  | `aHookIsNamedForItsFile`                                                                     | —                                                                                                                                                                                                                                                                 | The `use` prefix is what React's rules of hooks read.                                                                                                                                                    |
| A file in a drawer folder ends with its kind: in `utils/` `Utils` or `Adapters`, in `constants/` `Constants` or `Words`, in `types/` `Types` or `Answers`, in `providers/` `Provider`, in `services/` `Service`; in `utils/` a purpose stands before it, never the component's name alone (`boardPageTonesUtils.ts`, not `boardPageUtils.ts`).                                                                                                                                                                | `aFileNamesItsPurpose`                                                                       | —                                                                                                                                                                                                                                                                 | The folder says the kind, the closing word says it again where the file is read alone: in an import, a search, a tab.                                                                                    |
| A component's internal file carries the component's name: PascalCase for a component or a provider (`ItemListRow.tsx`, `ItemListProvider.tsx`), `use` + PascalCase for a hook (`useItemListFilters.ts`), camelCase for the rest (`itemListTypes.ts`, `itemListWords.ts`, `getItemListDataService.ts`, `useItemListQuery.ts`).                                                                                                                                                                                 | `aComponentFolderIsStructured`                                                               | a global file under `app/`, named by its domain instead                                                                                                                                                                                                           | At an import, the prefix says which component a file belongs to; two organisms can each have a `Header`.                                                                                                 |
| A service is `{verb}{Noun}Service.ts` and exports one function of that name.                                                                                                                                                                                                                                                                                                                                                                                                                                  | `aServiceIsOneFunction`                                                                      | `handleRouteService.ts`, the edge kernel, and its parts in `app/services/handleRoute/`, named by their job                                                                                                                                                        | The file's name is the function's name, so one search finds both.                                                                                                                                        |
| Types are `{area}Types.ts`, or `{area}Answers.ts` for what an endpoint answers; constants `{feature}Constants.ts`, copy `{name}Words.ts`; a provider `{Domain}Provider.tsx`; a route handler `{action}Route.ts`.                                                                                                                                                                                                                                                                                              | `aFileNamesItsPurpose`                                                                       | —                                                                                                                                                                                                                                                                 | The suffix says what kind of file it is before it is opened.                                                                                                                                             |
| A helper file is `{name}{Purpose}Utils.ts`, or `{name}{Purpose}Adapters.ts` for one that maps domain values to a component's props (`editorScreenImageUtils.ts`, `typeLibraryDocumentAdapters.ts`), wherever it lies. A purpose stands between the prefix and the suffix: never `typeLibraryUtils.ts`, `utils.ts`, `helpers.ts`, `common.ts`, `shared.ts`, or an `index.ts` that is not a barrel.                                                                                                             | `aFileNamesItsPurpose`                                                                       | the 21 files on its list, which only shrink                                                                                                                                                                                                                       | The suffix says the kind, as `Types` and `Constants` do, even where no folder says it; the purpose says the job, so `typeLibraryUtils.ts` cannot become a drawer.                                        |
| A value a `Constants` or `Words` file exports is UPPER_SNAKE (`MOVE_LIST_SX`, `CONTROL_LABELS`); a function it exports is camelCase (`documentPathOf`), a component PascalCase.                                                                                                                                                                                                                                                                                                                               | `aConstantIsUpperCase`                                                                       | none                                                                                                                                                                                                                                                              | At the call site the case says whether a name is read or called; six of 379 values were camel and read like helpers.                                                                                     |
| An import that leaves its unit reads the alias (`@/app/components/atoms/Text`, `@/tests/helpers/asCookie`); a relative path stays inside the unit (`./PlantedCell`, `../types/…`). A unit is a component's folder, `app/components/icons`, another top folder of `app/`, or the root files together. Inside `packages/domain` every import is relative: a package has no alias of its own.                                                                                                                    | `anImportLeavesByTheAlias`                                                                   | none                                                                                                                                                                                                                                                              | A component moved between layers keeps its own imports, one module has one spelling to grep and to scan, and the path says the layer; 393 relative imports into the layers stood beside 68 by the alias. |
