# Constants

Values the code reads and never computes: URLs, route paths, keys, the words a person reads.

| Rule                                                                                                                                                                                                                                                            | Gate                                                                            | Exceptions | Why                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ---------- | ------------------------------------------------------------------------------- |
| `app/constants/` is flat, one file per feature (`refusalKindsConstants.ts`, `documentWords.ts`); a component's own constants sit in its `constants/` (`names.md`).                                                                                              | `theMapIsTheTree` (no sub-folder) · `aComponentFolderIsStructured`              | —          | A constant is found by its feature's name, in one place.                        |
| A URL the browser calls is in `frontendApiConstants.ts` (`one-home.md`); one the server calls outside the app goes to `backendApiConstants.ts`, written the day there is one, and reads `process.env` on the server only.                                       | `aUrlIsWrittenOnce`                                                             | —          | Each side knows its next hop, and no browser bundle carries a server's address. |
| A page's path is in `appRoutesConstants.ts`.                                                                                                                                                                                                                    | `urlsForMapsEveryTarget` · `review`                                             | —          | A link and a redirect cannot point at two spellings of one page.                |
| A word a person reads is a constant (`{name}Words.ts`) or the domain's own sentence, never a literal in the markup (its text, a string child, a label a reader hears); a table of words (`…_WORDS`) is declared in a Words file.                                | `aWordIsNotInTheMarkup` · `copyLivesInAWordsFile` · `theWordsFollowTheGlossary` | —          | A word is changed in one place and reads the same on every screen.              |
| A count picks its form in `byCount` alone: a noun with its count is data, `countedNoun(count, { one, many })` with the nouns in the words table; a sentence whose verb or pronoun moves with the count is two whole sentences, `byCount(count, { one, many })`. | `aCountIsReadOnce`                                                              | —          | No screen reads "1 blocks", and a form is changed where the noun is written.    |
