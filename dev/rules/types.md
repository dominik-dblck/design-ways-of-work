# Types

A type holds the values the code can meet and no others. The review's sweep for it is
`.claude/evaluations/types-eval.md`, its first pass.

| Rule                                                                                                                                                                                                                                                                                                                                   | Gate                                                            | Exceptions                                                                                                                                                                                                    | Why                                                                                                                                      |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| No `any`.                                                                                                                                                                                                                                                                                                                              | ESLint `no-explicit-any`                                        | —                                                                                                                                                                                                             | `any` switches the checker off for everything the value touches.                                                                         |
| An exported function states its parameter and return types.                                                                                                                                                                                                                                                                            | ESLint `explicit-module-boundary-types`                         | —                                                                                                                                                                                                             | The signature is the contract a caller reads; an inferred one changes when the body does.                                                |
| A type-only import is `import type`.                                                                                                                                                                                                                                                                                                   | ESLint `consistent-type-imports`                                | never together with `verbatimModuleSyntax`, which conflicts with it                                                                                                                                           | It is erased at build, so a client bundle never pulls a server module in through a type.                                                 |
| A `switch` over a union handles every member.                                                                                                                                                                                                                                                                                          | ESLint `switch-exhaustiveness-check`                            | —                                                                                                                                                                                                             | A member added to the union is a red line at every switch, not a silent fall-through.                                                    |
| A field always present is not optional; shapes that differ are a discriminated union (`{ kind: 'error'; message } \| { kind: 'ok'; data }`), not one shape of optional fields; a union of literals stands where a boolean flag would.                                                                                                  | `review`                                                        | —                                                                                                                                                                                                             | Each shape says what it carries, so no reader checks a field the shape cannot have.                                                      |
| Data nobody mutates is `readonly` (`readonly T[]`, `.readonly()` on a schema).                                                                                                                                                                                                                                                         | `dataIsReadonly`                                                | a function's local · a `declare module` augmentation, which follows its library · a ref's `current` · the working states and library hand-offs `tests/architecture/mutableByDesign.json` names with their why | A mutation becomes a compile error instead of a shared-state bug.                                                                        |
| The code compiles under one base both sides extend, `shared/tsconfig.base.json`: `strict` and the checks beside it; a side's own tsconfig adds its environment alone (target, modules, types, paths).                                                                                                                                  | `yarn tsc` (pre-commit)                                         | —                                                                                                                                                                                                             | Strict is the floor every rule above stands on, and one base keeps both sides on one floor.                                              |
| A brand is a zod brand declared in its home (`z.string().min(1).brand<'BlockId'>()`; the build side's `packages/domain/model/brands/`), never `string & { __brand }`.                                                                                                                                                                  | `brandsCrossOnce` · `review`                                    | —                                                                                                                                                                                                             | The zod brand has a `parse`; the hand-written one can only be entered by a cast.                                                         |
| A schema is strict at every depth (`z.strictObject`), an answer read off the wire as much as a body, a payload or a record: a key it does not name is refused.                                                                                                                                                                         | `aSchemaIsStrict`                                               | the two that read part of something bigger: a refusal read for its reason in `getDiffService`, the clipboard's copy · a `.catchall` names its keys too                                                        | Drift between the server and a screen fails a test, not a reader; one style, since an answer's rows were strict already.                 |
| No deprecated API: what a declaration marks `@deprecated` is replaced by what it names instead.                                                                                                                                                                                                                                        | `review`                                                        | until its port, each deprecated call replaced or held in `eslint-suppressions.json`                                                                                                                           | A deprecated call breaks on its library's next major, and its successor is already written down.                                         |
| A type takes the highest rung its set of values allows: a literal union (`'rule' \| 'store'`, `keyof typeof THE_TABLE`), then a narrowing tied to a sibling (`FactsFor<K>`, `Record<RefusalKey, Refusal>`), then a brand, then a primitive, which is left for a value that is open (free text a person typed, an id minted elsewhere). | `review`                                                        | a field holding a row nobody parsed stays a primitive: a brand stops at the port (`StoredState.builtBy?: string`)                                                                                             | A primitive where the set is known lets a wrong value compile.                                                                           |
| A brand is minted where a value is checked or produced, by a schema parsing `unknown` or by a generator writing a literal, never to satisfy a signature; a payload field is branded by its schema, not by a table.                                                                                                                     | `brandsCrossOnce` · `payloadBrandsComeFromTheSchema`            | the files the scan lists, each with why it checks or produces · a runtime test that builds the value a refusal needs                                                                                          | A constructor called to please a signature is a cast with a function's name, and it moves the check to where nothing checks.             |
| A cast (`as`, `<T>`) appears only where a brand is minted; anywhere else it is let through in place by a directive with its reason.                                                                                                                                                                                                    | ESLint `consistent-type-assertions` (`assertionStyle: "never"`) | `as const` · tests · fixtures · generated files · the files `castingFiles.json` names, which `brandsCrossOnce` reads too                                                                                      | A cast is the one place the compiler takes the code's word for it.                                                                       |
| An opaque id is never read for meaning: no split, slice or regex over a `UserId` or a stream id, and no caller filters streams by a prefix.                                                                                                                                                                                            | `nothingParsesAUserId` · `streamIdIsOpaque`                     | —                                                                                                                                                                                                             | Initials and paths are not a contract: after a move the id says one folder and the state another.                                        |
| A version is counted and named by its doors: `versionAfter`, `versionBefore`, `versionsThrough` count it, `versionTag`, `versionLabel` name it; no `(version ?? 0) + 1`, `version - 1` or `` `v${…}` `` anywhere else.                                                                                                                 | `aVersionIsCountedOnce`                                         | —                                                                                                                                                                                                             | Four screens counted the next version by hand, two of them from a draft, and a tag spelled by hand reads `v0` where the door refuses it. |
| A shape the server and a screen both read is the domain's: its zod schema and its inferred type side by side in `packages/domain/{area}/` (`documentRowSchema`, `DocumentRow = z.infer<…>`); `app/` holds no types folder.                                                                                                             | `theMapIsTheTree` (no types folder under `app/`) · `review`     | an organism's own props, in its `types/`                                                                                                                                                                      | One schema is both the check at the door and the type behind it.                                                                         |
| No `@ts-ignore`; `@ts-expect-error` stands only in a `*.test-d.ts`, where it is the proof, and every brand has one there proving it rejects the swap.                                                                                                                                                                                  | ESLint `ban-ts-comment` · `review` (a brand's proof)            | —                                                                                                                                                                                                             | A brand nobody proved rejects the swap is a brand nobody checked.                                                                        |
