# Styling

The look comes from the design system's tokens through one MUI theme; a component names a role,
never a value. MUI's own rules: `.claude/patterns/mui7.md`, until the pipeline's sync brings them
here.

A renderer under `app/renderers/` draws another app, Deblock's, as Figma draws it: its own ink,
type and pixels, never the theme's. The two rules on spaces and heights leave it out.

| Rule                                                                                                                                                                                                                                                                                               | Gate                                                                                    | Exceptions                                                                                                                      | Why                                                                                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| A component writes no height; a corner, a layer, a weight and a fade are read by name off the design system's scales (`radiusOf('uiRCard')` on `borderRadius`, in the theme's units; a length on one corner, in px), never written as a number (a corner `0` or `'50%'`, a fade `0` or `1` aside). | `noComponentWritesAHeight` · `aStyleReadsItsScale`                                      | `app/renderers/**`, Figma's heights · the scale file itself (`app/styles/theme.ts`, `sizeSmall: { height: HEIGHT.small }`)      | Size follows content, layers stack in one known order, and a step of a scale moves in one place. |
| An sx object is written `as const`, checked where it is read; a function of the theme is typed `SxProps<Theme>`.                                                                                                                                                                                   | `anSxIsAsConst`                                                                         | —                                                                                                                               | One form, checked where it is read · a type on the object widens what it holds.                  |
| `app/styles/tokens.ts` is generated by `scripts/generateTokens.ts` from the design system's two stylesheets in `app/styles/__fixtures__/`, whose hashes the design side took; it is never edited.                                                                                                  | `tokensAreGenerated`                                                                    | —                                                                                                                               | The tokens are the design side's; a hand edit is a value nobody designed.                        |
| `app/styles/theme.ts` builds one theme with both colour schemes from the two token objects, under the `data-theme` selector; no file writes a palette of its own, and no file under `app/styles/` reaches past the tokens to a primitive (`gray`, `brand`, `hsl(`, `alpha(`).                      | `theThemeHasBothModes` · `noPrimitiveReachesTheTheme`                                   | —                                                                                                                               | Light and dark come from one source, so neither drifts.                                          |
| A colour is a palette role (`primary.main`), never a hex, a token variable or the light palette's value; text colour is a tone of `Text`, `Eyebrow` or `Label`, never a Typography's `color` or a colour in its sx.                                                                                | `aColourIsAPaletteRole` · `aTextColourIsATone` · `noComponentCarriesAColour` · `dsScan` | The push preview's title (the phone's own paint) and a document row's name (an anchor `Text` does not draw), named in the scan. | A role follows the mode; a value is right in one of the two.                                     |
| Every token an atom variant names resolves in both modes, and every theme value is either an atom's token or a listed literal.                                                                                                                                                                     | `theAtomsAreTheTheme`                                                                   | —                                                                                                                               | An atom cannot point at a token the theme does not hold.                                         |
| A name stands on its scale: a layer in `LAYERS`, a weight the theme's `fontWeight…`, a fade a step of `FADE`, a radius role a `uiR…` token; spacing comes from the theme.                                                                                                                          | `aStyleReadsItsScale` (a name on its scale) · `aSpaceIsInThemeUnits` · `dsScan`         | the phone's and a layout's thumbnail corners (`PhonePreview`, `LayoutPreview`), which draw iOS and Android                      | A step of a scale moves in one place.                                                            |
| The brand font is three `.woff2` faces loaded once, by `app/styles/font.ts`, its class on the layout's `<html>`.                                                                                                                                                                                   | `theFontsAreShapeChecked`                                                               | —                                                                                                                               | One font, loaded once, and no stray `@font-face`.                                                |
| The mode (light, dark or system) is read from a cookie by `app/styles/appearance.ts`, and `TokenVariables.tsx` writes the tokens as CSS variables for each.                                                                                                                                        | `theModeIsReadOnce`                                                                     | —                                                                                                                               | The page renders in the right mode before any script runs.                                       |
| A contrast ratio is computed by `app/styles/contrast.ts`, the one WCAG formula.                                                                                                                                                                                                                    | `noComponentCarriesAColour` (contrast)                                                  | —                                                                                                                               | One formula, so two checks cannot disagree.                                                      |
| An image or file the design side owns is the one the manifest names, hashed.                                                                                                                                                                                                                       | `assetsMatchTheManifest`                                                                | —                                                                                                                               | An asset is the design side's, byte for byte.                                                    |
