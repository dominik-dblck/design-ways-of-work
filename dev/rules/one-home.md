# One home

A fact is written in one place, and everything else reads it from there.

| Rule                                                                                                                                                                                                           | Gate                                                                                                                      | Exceptions                                                                                                                                                         | Why                                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| An exported name — a value, a type, a component — is declared in one file.                                                                                                                                     | `aNameHasOneHome`                                                                                                         | an HTTP verb in a `route.ts` · `default`                                                                                                                           | Two declarations of one name are two things a reader takes for one, or one thing written twice.                                                            |
| A block of code is written once: fifty tokens alike, in two files or twice in one, become one function, type or constant that both read.                                                                       | `aBlockIsWrittenOnce`                                                                                                     | imports · tests, fixtures and generated files                                                                                                                      | Two copies of a rule change apart and the fix reaches one; fifty tokens is jscpd's default, and a look-alike under it is judged by whether it is one rule. |
| No runtime import cycle.                                                                                                                                                                                       | `noImportCycles`                                                                                                          | type-only imports                                                                                                                                                  | A cycle lets load order decide behaviour, and a module mock does not survive it.                                                                           |
| A generated file is emitted from its source and never edited by hand.                                                                                                                                          | `theEmittedFilesAreFresh` · `tokensAreGenerated` · `theBodiesAreEmitted` · `theQueryIdsAreEmitted` · `skillsAreGenerated` | —                                                                                                                                                                  | A hand edit is lost on the next emit, or kept while its source says otherwise.                                                                             |
| A path a skill or a doc names in backticks exists; what the code lacks is removed from the doc, not kept as advice.                                                                                            | `theDocsNameRealPaths`                                                                                                    | a placeholder (`{name}`, `*`) · a doc a script renders · the entries on its list, which only shrink                                                                | A doc that names a missing path sends its reader looking for nothing.                                                                                      |
| `export … from` stands only in a barrel (`index.ts`), and a barrel re-exports its own folder, never another barrel.                                                                                            | `reExportsLiveInBarrels`                                                                                                  | a `route.ts` re-exporting its handler, the App Router's door                                                                                                       | A re-export elsewhere is a second door to one name; a barrel of barrels loads everything behind it.                                                        |
| A sentence is written once, in code and in the `.md` under `.claude/` and `docs/rules/`; a sentence the domain holds is read from the domain.                                                                  | `aSentenceIsWrittenOnce` · `theWordsFollowTheGlossary`                                                                    | fixtures copied byte-exact from the design side                                                                                                                    | Two copies of a sentence are two places for it to differ.                                                                                                  |
| A label is written once: a string of twelve characters or more, opening with a capital and holding a space, in one production file; a member of a declared set (`z.enum`, a literal type, a key) is the set's. | `aLabelIsWrittenOnce`                                                                                                     | generated files, whose sheet copy holds them                                                                                                                       | A label under a sentence's six words differs between two copies as a sentence does; a set's member is checked by the compiler wherever it stands.          |
| A shape is written once: an expression of twelve nodes or more, its local names and literals made alike and its property names kept, found in three files or more, becomes one function the files read.        | `aShapeIsWrittenOnce`                                                                                                     | a shape holding JSX (the look's scans hold it) · literals alone (data) · a call or an object that only hands names on · `coincidentShapes.json`, each with its why | Under a block's fifty tokens a rule still parts from its copies; a comparator stood in seven files, none of them fifty tokens long.                        |
| A URL is written once, in `frontendApiConstants.ts`; a path the domain holds (`ASSETS_PATH`) is read from the domain.                                                                                          | `aUrlIsWrittenOnce`                                                                                                       | —                                                                                                                                                                  | A URL written inline in a caller is the same fact in two places.                                                                                           |
| A count a document states is checked against what it counts.                                                                                                                                                   | `statedCounts`                                                                                                            | —                                                                                                                                                                  | A stated count goes stale the day one more thing is added.                                                                                                 |
