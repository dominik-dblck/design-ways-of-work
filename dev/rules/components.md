# Components

`app/components/` in atomic design: a tier is counted from what a component imports, never judged
from its size.

| Rule                                                                                                                                                                                                                                                                                              | Gate                                                     | Exceptions                                                                                                         | Why                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| A tier is what a component imports from `app/components/`: an atom nothing, a molecule atoms and at most one other molecule, an organism two or more molecules or a screen's own flow, a template a page's layout.                                                                                | `anAtomComposesNothing` · `aMoleculeComposesOneMolecule` | —                                                                                                                  | Counted, not judged, so two people sort a component the same way.                     |
| A component file holds one component and its props type; a second component goes to `components/`, a type to `types/`, a helper to `utils/`, a constant to `constants/`, a hook to `hooks/`.                                                                                                      | `oneComponentAFile` · `aComponentFileHoldsItsComponent`  | an icon: one flat file, its path data beside it                                                                    | A file opened for a component shows that component and nothing else.                  |
| An atom is one element over MUI and the theme; joined with another atom it is a molecule (`HintButton`, not a `Button` with two more props). A neighbour's id comes in as a prop (`describedBy`), and an atom under a `Hint` passes on its listeners and its ref.                                 | `anAtomComposesNothing`                                  | —                                                                                                                  | A prop that adds a neighbour is a second component hiding in the first.               |
| A molecule imports no organism, template, query, command or `useContext`.                                                                                                                                                                                                                         | `aMoleculeComposesOneMolecule` · `theMoleculesAreDumb`   | —                                                                                                                  | It draws what it is handed, so every screen can use it.                               |
| An organism is reached through its barrel: a page mounts one, and an organism may render another (`NameDialog`) only through `organisms/{Name}`.                                                                                                                                                  | `organismsMeetAtTheBarrel` · `theStripIsNotTheShells`    | one slot component exported beside the organism for the shell's header (`TypeLibraryHeader`, `EditorScreenHeader`) | The barrel is the organism's face; the files behind it can move.                      |
| Every component has the organism's folder shape: the root holds `{Name}.tsx` and `index.ts`, every other file sits in `components/`, `hooks/`, `utils/`, `types/`, `constants/`, `providers/`, `services/` or `__tests__/`, prefixed (`names.md`).                                                | `aComponentFolderIsStructured`                           | an atom has no `components/`, having no parts                                                                      | One shape everywhere, so a file is found without a search.                            |
| Every organism a page mounts is a flow organism; it keeps one view per state in `components/state-views/` and switches between them (`EditorScreenLoadingView`, `EditorScreenReadyView`).                                                                                                         | `aScreenIsAFlowOrganism`                                 | `Campaigns`, on the scan's baseline until the documents by type and kind replace it                                | Each state reads on its own, and the switch is the one place that chooses.            |
| `@mui/material` is imported under `app/components/` only.                                                                                                                                                                                                                                         | `theWrappersAreTheDoor`                                  | —                                                                                                                  | A change to how MUI is used lands in the wrappers, not across the screens.            |
| Every component is a row of `app/styles/components.spec.json`, copied from the design side, or on the roster of organisms this repository owns.                                                                                                                                                   | `nothingIsUnnamed` · `theComponentSpec`                  | —                                                                                                                  | A shape the wireframes do not draw is a question to the design side, not a component. |
| A test id comes from `e2e/testingIds/`, never a literal.                                                                                                                                                                                                                                          | `testIdsComeFromTheRegistry` · `testIdsArePrefixed`      | —                                                                                                                  | The browser tests reach every element through one registry.                           |
| Hover text is a `Hint`; no element carries a `title`.                                                                                                                                                                                                                                             | `hoverTextIsAHint`                                       | —                                                                                                                  | One look and one delay for every hover.                                               |
| A heavy component the first screen does not need loads through `next/dynamic` (`RichTextField`).                                                                                                                                                                                                  | `theRichTextEditorLoadsOnDemand`                         | —                                                                                                                  | The editor's code stays out of the first load.                                        |
| Every glyph is Lucide's, through `atoms/Glyph`, by name and a theme step (`small`, `medium`, `large` for a control; `dot`, `badge`, `inline` for a mark), never a number; `glyphSetConstants.ts` is the one importer of `lucide-react`, pinned to an exact version; the colour is `currentColor`. | `theIconSet`                                             | —                                                                                                                  | One set, one stroke, sizes from the tokens.                                           |
| `components/icons/` holds only what Lucide has no glyph for, the brand marks and the one-offs: one flat file each, named exports, no barrel, `IconProps` with one `size`; no `<svg>` is drawn by hand anywhere else.                                                                              | `theIconSet`                                             | —                                                                                                                  | Two numbers for one size are two numbers a call site can set out of proportion.       |

## The folder shape

```
components/atoms/Button/
  Button.tsx                         # the component and its props type
  index.ts                           # the barrel
  constants/buttonConstants.ts
  types/buttonTypes.ts
components/organisms/ApprovalBar/
  ApprovalBar.tsx
  index.ts
  components/ApprovalBarActions.tsx  # one component each
  constants/approvalBarWords.ts
  types/approvalBarTypes.ts
  utils/approvalBarToDoUtils.ts
```
