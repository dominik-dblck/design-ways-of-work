# Responsibility

A file does one job, and its first lines say which.

| Rule                                                                                                                                                                                                                                                   | Gate                                                                         | Exceptions                                                                                                  | Why                                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| A production file, under `app/`, `packages/` or `scripts/`, opens with a header of 1–3 bullets, each at most 80 characters.                                                                                                                            | `aFileStatesItsJob`                                                          | barrels · a `route.ts` that only re-exports · generated files · tests                                       | A fourth bullet is the file's second job showing; the split goes there.                                                               |
| Each bullet names, in backticks, the exports it describes; every exported value is in a bullet, and every name in backticks exists in the file.                                                                                                        | `aFileStatesItsJob`                                                          | exported types, the vocabulary the bullets are written in                                                   | A rename or a new export turns the gate red instead of leaving the header to lie.                                                     |
| A file exports at most 15 values.                                                                                                                                                                                                                      | `aFileStatesItsJob`                                                          | exported types · barrels · generated files                                                                  | Past 15 a file is a catalogue, and three bullets cannot say what it is.                                                               |
| A value a production file exports is read by another file: imported by name, or with its module whole (`* as`, `export *`, `import()`, a glob); one only its own file reads is not exported.                                                           | `anExportIsRead`                                                             | what Next reads off a file by its name (a route's verbs, a page's `metadata`) · a default · generated files | An export no file imports is a door to nothing: its reader takes it for part of the file's offer.                                     |
| A file is read as one: its exported values, grouped by the production files that read them, are one job where a reader reads two of them, one uses the other, or both use a declaration the file keeps to itself; a file of two jobs or more is split. | `aFileIsReadAsOne`                                                           | a group one file reads alone · types · the files on `readAsOne.json`, each with its why                     | Readers that never meet are two reasons to change kept in one file; a scan cannot see a subject, so the list says it where one holds. |
| Each kind of code has its folder: rendering in `components/`, behaviour in `hooks/`, calls in `services/`, shared state in `providers/`, pure helpers in `utils/`, types in `types/`, words and values in `constants/`.                                | `aComponentFolderIsStructured` (the folders) · `review` (what lands in each) | a component file holds its own props type                                                                   | A file in the wrong folder is a file nobody looks for there.                                                                          |
| A screen holds no rule of the domain; it reads the domain's answer.                                                                                                                                                                                    | `theScreenReadsNoRules`                                                      | —                                                                                                           | A rule copied onto a screen is decided twice, and the copies drift.                                                                   |
| Code one organism uses stays inside it; code several organisms use moves to the app folder of its kind; an entity's calls belong to `app/clients/{entity}/` from the first caller.                                                                     | `aFileLivesWithItsOnlyUser`                                                  | —                                                                                                           | A shared folder filled ahead of a second caller collects code nobody owns.                                                            |
| A global folder (`app/services/`, `app/hooks/`) starts flat and groups a feature's files into a folder of their own once it holds several.                                                                                                             | `review`                                                                     | —                                                                                                           | A flat folder reads at a glance until one feature crowds it.                                                                          |
